# لقمة — عرض تجريبي لتوصيل الطعام

موقع تجريبي بالعربية فقط (RTL) لطلب الطعام من المطاعم.

## التشغيل

```bash
npm install
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000)

## المميزات

- صفحة رئيسية احترافية
- 5 مطاعم × 5 وجبات (بيانات وهمية)
- بحث، سلة، محفوظات، طلب تجريبي بدون دفع حقيقي
